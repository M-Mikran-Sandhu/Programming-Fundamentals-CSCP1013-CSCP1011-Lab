# 16 - Python loops and lists

## What it does
Reads the marks of 5 students into a list (asking again if the input is invalid), then prints each mark, the total, the average, the highest, the lowest and how many students passed (50 or more).

## Concepts used
- Lists and `append()`
- `for` loop with `range()`
- `while True` with `break` for input validation
- Looping through a list
- `and` to check two conditions safely

## Sample run
```
Enter marks of student 1 (0 to 100): 70
Enter marks of student 2 (0 to 100): 85
Enter marks of student 3 (0 to 100): 90
Enter marks of student 4 (0 to 100): 65
Enter marks of student 5 (0 to 100): 80

Student 1 : 70
Student 2 : 85
Student 3 : 90
Student 4 : 65
Student 5 : 80

Total  : 390
Average: 78.0
Highest: 90
Lowest : 65
Passed : 5 out of 5
```

## What I learned
A for loop repeats a fixed number of times, a while loop repeats until a condition changes, and a list stores many values that I can add to with append() and visit with a for loop.
